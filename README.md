# Dinesh Kumar Portfolio

A polished React + Vite portfolio website ready to upload to GitHub and deploy with GitHub Pages, Netlify, or Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated in the `dist` folder.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload everything in this folder except `node_modules` and `dist`.
3. In GitHub Pages, choose GitHub Actions or deploy from the built `dist` folder.

This app uses hash routing and relative asset paths, so it works under GitHub Pages repository URLs.
